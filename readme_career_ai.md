# Career AI — Интеллектуальный помощник по поиску работы

**Career AI** — это веб-приложение на базе искусственного интеллекта (Google Gemini API), созданное для студентов, выпускников, начинающих специалистов и людей, меняющих профессию (свитчеров). Сервис помогает адаптировать резюме под требования конкретной вакансии с учётом стандартов рынка труда Казахстана (`hh.kz`) и систем автоматического отбора (ATS), составить план закрытия пробелов в навыках и подготовиться к собеседованию по методике **STAR**.

## 🎯 Проблема и целевая аудитория

Многие начинающие специалисты и кандидаты без коммерческого опыта сталкиваются со сложностями при поиске работы:

* Отправляют одно шаблонное резюме на все вакансии и получают отказы без объяснения причин.

* Не знают, как правильно упаковать учебные проекты, стажировки или переносимые навыки из прошлой профессии.

* Не понимают, какие ключевые слова и инструменты из описания вакансии критичны для прохождения ATS-фильтров.

* Испытывают тревогу перед собеседованиями из-за неумения структурно рассказывать о своём опыте.

**Целевая аудитория:**

* Студенты старших курсов и выпускники вузов / колледжей.

* Начинающие специалисты (Junior) любых направлений.

* Кандидаты, меняющие сферу деятельности (свитчеры).

## ✨ Основные возможности

1. **Загрузка резюме в любом удобном формате**

   * Поддержка файлов **PDF**, **DOCX** и **TXT** (до 5 МБ) с извлечением текста прямо в браузере (без сохранения документов на сторонних серверах).

   * Возможность ручного ввода или быстрого тестирования на **4 встроенных демо-сценариях** (*Архитектор-выпускник*, *Маркетолог-студент*, *Junior Python-разработчик*, *Смена профессии: учитель → HR*).

2. **Комплексный ИИ-анализ соответствия вакансии**

   * Расчёт процента совпадения (`0–100%`) по взвешенной формуле: **50%** обязательные требования, **25%** ключевые слова и ПО (ATS), **15%** опыт и достижения, **10%** образование и языки.

   * Автоматическое извлечение образования, навыков и опыта кандидата.

   * **Gap-анализ:** разделение требований на *«Что уже подходит»* и *«Чего не хватает»* с пояснениями.

3. **Улучшение резюме и экспорт**

   * Точечные рекомендации по разделам резюме с опорой на формулу достижений **«Действие + Цифра/Результат»**.

   * Генерация готового адаптированного текста резюме **без выдумывания фактов** о кандидате.

   * Экспорт улучшенного резюме и полного отчёта анализа в форматы **PDF** (с поддержкой кириллицы) и **TXT**.

4. **Персональный план развития на 4 недели**

   * Приоритизация до 5 недостающих навыков с указанием формата практики для портфолио.

   * Интерактивный график по неделям (Недели 1–4) с чек-листом задач и выгрузкой в **TXT**.

5. **Тренажёр собеседования по методу STAR**

   * Генерация 5 целевых вопросов (профессиональных кейсов по пробелам кандидата и поведенческих вопросов).

   * Разбор ответов пользователя по шкале `1–10` с проверкой 4 элементов: **S**ituation (Ситуация), **T**ask (Задача), **A**ction (Действие), **R**esult (Результат) и примером сильного ответа на базе реальных фактов из резюме.

6. **Режим тестирования и оценка качества**

   * Встроенная телеметрия (время ответа ИИ в секундах, расход токенов, активная модель) и система оценки полезности каждого блока (`👍 / 👎`).

## 🧠 Встроенная база знаний (9 разделов правил)

В системный промпт ИИ интегрирована база знаний HR-рекрутинга, обеспечивающая точность и этичность рекомендаций:

1. Чек-лист HR-рекрутера под рынок Казахстана и стандарты `hh.kz`.

2. Проверка точных ключевых слов и инструментов для систем ATS.

3. Формула достижений *«Действие + Цифра/Результат»*.

4. Правила упаковки учебных проектов для студентов и переносимых навыков для свитчеров.

5. Отраслевые подсказки по 9 профессиональным сферам (архитектура, IT, маркетинг, дизайн, финансы, образование, медицина, право, сервис/HR).

6. Прозрачная взвешенная формула оценки соответствия (`50/25/15/10`).

7. Критерии генерации вопросов и оценки ответов по методу **STAR**.

8. Этика и защита персональных данных (игнорирование пола, возраста, национальности, фото; рекомендации по удалению лишних личных данных).

9. Универсальность по профессиям и строгий запрет на «галлюцинации» (выдумывание опыта или требований).

## 🛠 Технологический стек

* **Frontend:** React, TypeScript, Vite, Tailwind CSS, Lucide Icons

* **ИИ-ядро:** Google Gemini REST API (`gemini-3.1-flash-lite-preview` с автоматическим fallback на `gemini-3-flash-preview` и `gemini-2.5-flash`) + опциональный Edge-прокси `/api/gemini` для деплоя на Vercel

* **Клиентский парсинг документов:** `pdf.js` (PDF), `mammoth.js` (DOCX), `FileReader` (TXT)

* **Генерация и экспорт отчётов:** `html2pdf.js` (PDF), `Blob API` (TXT)

## 🚀 Запуск и использование

### Вариант 1. Запуск в браузере (Standalone / Vercel)

1. Откройте приложение в браузере.

2. Нажмите кнопку **«Параметры ИИ»** в правом верхнем углу.

3. Вставьте ваш личный ключ **Gemini API Key** (получить бесплатно можно в [Google AI Studio](https://aistudio.google.com/apikey)) — ключ сохраняется локально в `localStorage` вашего браузера.

4. Выберите один из демо-сценариев или загрузите своё резюме и текст вакансии, затем нажмите **«Проанализировать соответствие»**.

### Вариант 2. Локальная сборка (для разработчиков)

```
# 1. Клонируйте репозиторий
git clone https://github.com/your-username/career-ai.git
cd career-ai

# 2. Установите зависимости
npm install

# 3. Запустите сервер разработки
npm run dev

```

*(Опционально)* Для работы серверного прокси `/api/gemini` на платформе **Vercel** добавьте переменную окружения в настройках проекта:

```
GEMINI_API_KEY=ваш_ключ_из_google_ai_studio

```
